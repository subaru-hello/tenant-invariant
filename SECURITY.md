# Security policy

This project is experimental and has not undergone a security audit. Do not treat it as the only enforcement layer in a production system.

Please report suspected vulnerabilities privately through [GitHub Security Advisories](https://github.com/subaru-hello/tenant-boundary-kit/security/advisories/new). Include the affected version or commit, impact, and a minimal reproduction when possible. Please do not open a public issue for an undisclosed vulnerability.
